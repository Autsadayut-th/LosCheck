## รายละเอียดของแต่ละไฟล์

### 1. [customer_page.dart](file:///c:/Users/E320/Downloads/Project/LosCheck-main/lib/screens/customer_page/customer_page.dart)
หน้าหลักแสดงรายชื่อลูกค้า (`CustomerPage` ซึ่งเป็น `StatefulWidget`)
- **การนำทางหลัก:** ถูกปรับปรุงเอา TabController ออกเพื่อความกระชับของหน้าจอ โดยจะแสดงลิสต์ลูกค้ารายการเดี่ยว ๆ และมีปุ่มลอย **FAB (`addCustomerFab`)** อยู่มุมขวาล่างเพื่อเปิดหน้าฟอร์มด้วย `Navigator.push`
- **ฟังก์ชันการทำงานหลัก:**
  - **การกรองข้อมูล (Filter & Debounce):** ค้นหาลูกค้าผ่านชื่อหรือเบอร์โทร โดยมีระบบ Debounce 250ms เพื่อลดภาระการประมวลผล
  - **การจัดเรียง (Sorting):** เรียงตามชื่อ (A-Z), เรียงตามวันที่เพิ่มล่าสุด, หรือเรียงกลุ่มลูกค้าที่ยังไม่มีพิกัด GPS ขึ้นมาก่อน
  - **การจัดการฐานข้อมูล (Database Actions):** ดึงข้อมูลสดแบบ Reactive จาก Hive Database ผ่าน Stream (`watchAllCustomers`) เพื่อแสดงผลล่าสุดอัตโนมัติ
  - **การโทรออก (Call Service):** ดึงเบอร์โทรของลูกค้าแล้วเปิดการโทรผ่านแอปโทรศัพท์ของเครื่อง (`url_launcher`)
  - **การนำทางผ่านแผนที่ (Map Navigation):** หากมีพิกัด (Lat, Lng) จะเปิด Google Maps เพื่อนำทางไปยังบ้านลูกค้า

### 2. [customer_form_page.dart](file:///c:/Users/E320/Downloads/Project/LosCheck-main/lib/screens/customer_page/customer_form_page.dart)
หน้าฟอร์มบันทึกข้อมูลแบบแยกเดี่ยว (`CustomerFormPage` ซึ่งเป็น `StatefulWidget`)
- **การเปิดใช้งาน:** ใช้เปิดผ่านปุ่ม FAB (โหมดเพิ่มลูกค้าใหม่) หรือเปิดผ่านปุ่มแก้ไข/แตะการ์ดลูกค้า (โหมดแก้ไขข้อมูลลูกค้าเดิม)
- **ฟังก์ชันวางข้อความอัจฉริยะ (Smart Paste):** มีการ์ดพับเก็บได้ด้านบนสุดสำหรับวางข้อความแชทดิบ เพื่อแกะหา ชื่อ เบอร์โทร ที่อยู่ และลิงก์แผนที่ Google Maps โดยใช้ Regex แล้วกรอกฟอร์มให้อัตโนมัติทันที
- **ระบบตรวจจับเบอร์โทรซ้ำ (Duplicate Phone Checking):** เมื่อกำลังกรอกเบอร์โทรศัพท์ในโหมดเพิ่มใหม่ ระบบจะตรวจเช็คกับฐานข้อมูลทันที หากพบว่ามีเบอร์นี้อยู่แล้วจะแสดง Dialog สอบถามความสมัครใจเพื่อดึงข้อมูลเก่าขึ้นมาอัปเดตแทน

### 3. [customer_sort_method.dart](file:///c:/Users/E320/Downloads/Project/LosCheck-main/lib/screens/customer_page/models/customer_sort_method.dart)
โมเดลเก็บประเภทการจัดเรียงข้อมูล (`CustomerSortMethod`)
- เป็นประเภท `enum` ประกอบด้วย:
  - `name`: จัดเรียงตามชื่อลูกค้าภาษาไทย/อังกฤษ (A-Z)
  - `dateAdded`: จัดเรียงตามวันที่และเวลาที่เพิ่มข้อมูล (จากใหม่ไปเก่า)
  - `coordinateStatus`: จัดเรียงโดยแสดงกลุ่มลูกค้าที่ไม่มีค่าพิกัด GPS ก่อน เพื่อสะดวกในการระบุตำแหน่ง

### 4. [customer_form.dart](file:///c:/Users/E320/Downloads/Project/LosCheck-main/lib/screens/customer_page/widgets/customer_form.dart)
วิดเจ็ตแสดงฟิลด์ฟอร์มกรอกข้อมูลลูกค้า (`CustomerForm` ซึ่งเป็น `StatefulWidget`)
- **ระบบติดตามความสมบูรณ์ (Completion Progress Indicator):** แสดงเปอร์เซ็นต์ความสมบูรณ์ของข้อมูลที่กรอก (เบอร์โทร 25%, ชื่อ 25%, ที่อยู่ 25%, พิกัดหรือลิงก์แผนที่ 15%, รูปภาพ 10%) พร้อมแถบสถานะ (LinearProgressIndicator)
- **ช่องกรอกข้อมูลประกอบด้วย:**
  - **เบอร์โทร:** ช่องใส่เบอร์โทรศัพท์ (มีระบบตรวจสอบความถูกต้องขั้นต่ำ 9 ตัว)
  - **ชื่อลูกค้า:** ช่องใส่ชื่อของลูกค้า
  - **ที่อยู่:** ช่องใส่ที่อยู่อย่างละเอียด
  - **ลิงก์แผนที่ Google Maps:** ช่องสำหรับคัดลอกลิงก์มาวางเพื่อดึงพิกัดอัตโนมัติ
  - **พิกัด (Latitude / Longitude):** ช่องรับตัวเลขทศนิยม พร้อมปุ่ม **"ใช้ตำแหน่งปัจจุบัน"** เพื่อตรวจจับ GPS ทันที
  - **รูปภาพบ้านลูกค้า:** ปุ่ม/กรอบสำหรับอัปโหลดภาพถ่ายตัวบ้าน
- เมื่อกรอกข้อมูลถูกต้องสมบูรณ์ จะแสดงเครื่องหมายถูกสีเขียว (Check Icon) ในแต่ละช่องกรอก

### 5. [customer_record_tile.dart](file:///c:/Users/E320/Downloads/Project/LosCheck-main/lib/screens/customer_page/widgets/customer_record_tile.dart)
วิดเจ็ตแสดงกล่องข้อมูลลูกค้าแต่ละคนในรูปแบบ Card (`CustomerRecordTile`)
- **การแสดงผล:**
  - แสดงภาพถ่ายบ้านลูกค้า (หากไม่มี จะแสดงเป็นไอคอนรูปโปรไฟล์สีเขียวเริ่มต้น)
  - แสดงชื่อและเบอร์โทรศัพท์ของลูกค้า
  - แสดงป้ายแจ้งเตือนสีส้ม **"ไม่มีพิกัด"** หากลูกค้าคนนั้นยังไม่ได้กำหนดพิกัดแผนที่
  - แสดงที่อยู่และพิกัดแผนที่ (Latitude, Longitude)
- **ปุ่มดึงคำสั่งด่วน (Action Buttons):**
  - **ปุ่มโทรออก:** โทรติดต่อลูกค้าโดยตรง
  - **ปุ่มแผนที่:** นำทางไปยังตำแหน่งบ้านลูกค้าผ่าน Google Maps
  - **ปุ่มรูปภาพ:** ดูรูปภาพบ้านขยายใหญ่ หรืออัปเดตรูปภาพใหม่
  - **ปุ่มแก้ไข:** เปิดหน้าฟอร์มแยก (CustomerFormPage) เพื่อทำการแก้ไขข้อมูลลูกค้า
  - **ปุ่มลบ:** ลบข้อมูลลูกค้าออกจากระบบ (มีกล่องยืนยันก่อนลบ)
- รองรับการแสดงผลทั้งแบบ **Normal** (แสดงปุ่มแบบไอคอนแถวยาว) และ **Compact** (แสดงปุ่มดึงคำสั่งผ่าน PopupMenu เพื่อความสะอาดตากระชับ)
