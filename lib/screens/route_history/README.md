# 📜 โมดูลประวัติการนำทาง (Route History Module)

หน้านี้ทำหน้าที่จัดการ แสดงผล เพิ่ม แก้ไข และลบประวัติการจัดส่งนำทางคิวลูกค้าแต่ละรอบของคนส่งของ

## 📂 โครงสร้างโฟลเดอร์และไฟล์
```
lib/screens/route_history/
├── README.md                      # เอกสารอธิบายโมดูล (ไฟล์นี้)
├── route_history_page.dart        # หน้าหลักของหน้าประวัติ (StatefulWidget)
└── widgets/
    ├── add_edit_history_dialog.dart # ป๊อปอัพฟอร์มสำหรับเพิ่มหรือแก้ไขประวัติด้วยตนเอง
    └── route_history_tile.dart     # การ์ดแสดงผลประวัติการจัดส่งแต่ละรายการ
```

## 🛠️ รายละเอียดการทำงานของไฟล์

1. **`route_history_page.dart`**:
   - เป็นหน้าจอ Entrypoint หลักที่ทำงานร่วมกับ `AppStateProvider` และดึงข้อมูลประวัติการนำทางมาจากฐานข้อมูล Hive
   - จัดการ State ในการลบข้อมูล (Delete Confirmation) และการสั่งทำรายการผ่านป๊อปอัพ Dialog

2. **`widgets/add_edit_history_dialog.dart`**:
   - วิดเจ็ตแบบฟอร์ม Dialog สำหรับระบุข้อมูลสองค่าหลักคือ: **จำนวนจุดส่ง (จุด)** และ **ระยะทางนำทาง (กิโลเมตร)**
   - มีระบบ Validation ป้องกันไม่ให้ป้อนข้อมูลติดลบหรือเว้นว่างไว้

3. **`widgets/route_history_tile.dart`**:
   - หน้าตาการ์ดแสดงผลสไตล์พรีเมียม บอกวันและเวลาที่ทำรายการสำเร็จ จำนวนจุด และระยะทาง
   - มีปุ่มลัดสองปุ่มสำหรับ **แก้ไขข้อมูล** และ **ลบรายการ** พร้อมการจัดฟอร์แมตวันที่ที่เข้าใจง่าย (เช่น วันนี้, เมื่อวาน, หรือ DD/MM/YYYY)
