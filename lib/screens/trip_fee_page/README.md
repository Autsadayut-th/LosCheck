# โฟลเดอร์ค่ารอบ (Trip Fee Page Refactored)

โฟลเดอร์นี้เก็บไฟล์ที่ถูกแยกส่วนย่อยออกจากหน้า `trip_fee_page.dart` เดิมที่มีความยาวกว่า 1,700 บรรทัด เพื่อให้อ่านโค้ด จัดการการทำงาน และพัฒนาต่อได้ง่ายขึ้น

---

## 📂 โครงสร้างโฟลเดอร์ (Folder Structure)

```text
lib/screens/trip_fee_page/
├── README.md                          # ไฟล์คำอธิบายโครงสร้าง (ไฟล์นี้)
├── trip_fee_page.dart                 # ไฟล์หลัก Entrypoint ของหน้าค่ารอบ (บันทึกค่ารอบ, นับเงิน, รายงาน)
├── models/
│   └── trip_fee_models.dart           # คลาสข้อมูลสรุป ได้แก่ DailyTripSummary, PeriodSummary, DistanceStats
└── widgets/
    ├── summary_panel.dart             # แผงการ์ดสรุปยอดเงินสีเขียวด้านบน (ยอดรวมประจำวัน, Export CSV, ล้างข้อมูล)
    ├── distance_action_card.dart      # การ์ดแต่ละช่วงระยะทางสำหรับกดบันทึกค่ารอบด่วน
    ├── record_tile.dart               # รายการแถวประวัติค่ารอบแต่ละรายการ (แก้ไข, ลบ)
    ├── daily_summary_tile.dart        # แถบแสดงสรุปข้อมูลรายวันในหน้าสรุปรายงาน
    ├── period_summary_tile.dart       # แถบแสดงสรุปข้อมูลรายสัปดาห์ / รายเดือน
    └── distance_stat_card.dart        # แถบแสดงสถิติตามระยะทางในหน้าสรุปรายงาน
```

## 📄 คำอธิบายรายละเอียดของแต่ละไฟล์ (File Descriptions)

### 1. `trip_fee_page.dart`
- **หน้าที่หลัก**: เป็นหน้าหลัก (Entrypoint) ที่คุม State และควบคุมการกดเปลี่ยนแท็บทั้ง 3 แท็บ (บันทึกค่ารอบ, นับเงิน, สรุปและรายงาน)
- **การทำงาน**:
  - โหลดประวัติและบันทึกค่ารอบลง Hive Database
  - จัดการคำนวณและประมวลผลช่วงวันที่ที่เลือก (`_selectedDate`)
  - คุมฟังก์ชันการส่งออก CSV (`_exportCsv`) และล้างข้อมูลประจำวัน
  - แสดงผลวิดเจ็ต `SummaryPanel`, `DistanceActionCard`, และ `RecordTile` ในหน้าหลักบันทึกค่ารอบ

### 2. `models/trip_fee_models.dart`
- **หน้าที่หลัก**: คลาสโครงสร้างข้อมูล (Data Models)
- **การทำงาน**:
  - `DailyTripSummary`: เก็บสรุปยอดเงิน ยอดรอบ และจำนวนรายการแยกรายวัน
  - `PeriodSummary`: เก็บสรุปยอดเงินและรอบแยกตามช่วงเวลา (รายสัปดาห์ หรือ รายเดือน)
  - `DistanceStats`: เก็บยอดรวมจำนวนรอบและยอดเงินที่วิ่งได้ตามระดับช่วงระยะทาง

### 3. `widgets/summary_panel.dart`
- **หน้าที่หลัก**: แผงสรุปยอดเงินรวมสีเขียวสวยงามที่ด้านบนของแอป
- **การทำงาน**: แสดงยอดเงิน ยอดรวมรอบของวันที่เลือก มีปุ่มสำหรับการเลือกวันผ่านปุ่มปฏิทิน และมีปุ่มสำหรับส่งออกไฟล์ CSV และล้างข้อมูลทั้งหมดในวันนั้นๆ

### 4. `widgets/distance_action_card.dart`
- **หน้าที่หลัก**: การ์ดแสดงผลระยะทางแต่ละระดับสำหรับกดเพิ่มรอบเดินทาง
- **การทำงาน**: 
  - เมื่อคลิกที่ตัวการ์ดจะเพิ่มรอบเดินทางอัตโนมัติ (1 รอบ) ด้วยอนิเมชันย่อตัวการ์ดเล็กน้อยตอนกด (Micro-interaction)
  - มีปุ่มทางขวาบน (ปุ่มรูปดินสอ) สำหรับเปิดหน้าต่างป็อปอัประบุจำนวนรอบส่งเฉพาะเองได้

### 5. `widgets/record_tile.dart`
- **หน้าที่หลัก**: รายการแถวแสดงประวัติแต่ละบิลของวันที่เลือก
- **การทำงาน**: แสดงผลระยะทาง จำนวนรอบ คูณด้วยอัตราค่าวิ่ง มีความสามารถตรวจจับการคลิกเพื่อเข้าหน้าจอแก้ไขค่ารอบหรือสั่งลบรายการนั้นๆ

### 6. `widgets/daily_summary_tile.dart`
- **หน้าที่หลัก**: แสดงสรุปยอดเงินรายวันแบบย่อแยกตามประวัติแต่ละวัน (เช่น วันนี้, เมื่อวาน) เพื่อแสดงผลในแท็บสถิติและรายงาน

### 7. `widgets/period_summary_tile.dart`
- **หน้าที่หลัก**: การ์ดสรุปประวัติภาพรวมของรายสัปดาห์หรือรายเดือน โดยสามารถใส่รูปแบบการฟอร์แมตป้ายกำกับปฏิทินเองได้

### 8. `widgets/distance_stat_card.dart`
- **หน้าที่หลัก**: แสดงผลสถิติเป็นไอคอนยานพาหนะตามประเภทความไกลของระยะทาง แสดงยอดเงินรวมของการวิ่งระยะทางแต่ละกลุ่มบนหน้าสถิติ
