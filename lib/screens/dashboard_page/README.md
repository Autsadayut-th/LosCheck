# โฟลเดอร์แดชบอร์ด (Dashboard Page Refactored)

โฟลเดอร์นี้เก็บไฟล์ที่ถูกแยกส่วนย่อยออกจากหน้า `dashboard_page.dart` เดิมที่มีความยาวกว่า 1,200 บรรทัด เพื่อให้อ่านโค้ด จัดการการทำงาน และพัฒนาต่อได้ง่ายขึ้น

---

## 📂 โครงสร้างโฟลเดอร์ (Folder Structure)

```text
lib/screens/dashboard_page/
├── README.md                          # ไฟล์คำอธิบายโครงสร้าง (ไฟล์นี้)
├── dashboard_page.dart                # ไฟล์หลัก Entrypoint ของหน้า Dashboard
└── widgets/
    ├── dashboard_map_content.dart     # คอมโพเนนต์หลักควบคุมแผนที่ ข้อมูลสรุป และฟังก์ชันทั้งหมด
    ├── action_button.dart             # ปุ่มกดสั่งการ (วางแผนและนำทาง) พร้อมอนิเมชันตอนกด
    ├── glass_search_bar.dart          # แถบค้นหาลูกค้ากึ่งโปร่งใสดีไซน์สวยงาม
    ├── customer_bottom_sheet.dart     # หน้าต่างแผ่นข้อมูลรายละเอียดของลูกค้าเดี่ยว
    ├── cluster_bottom_sheet.dart      # หน้าต่างแผ่นข้อมูลรายการลูกค้าในจุดที่มีพิกัดใกล้เคียงกัน
    └── fade_in_slide.dart             # คลาสอนิเมชันเอฟเฟกต์ค่อยๆ แสดงผลและเลื่อนขึ้น
```

---

## 📄 คำอธิบายรายละเอียดของแต่ละไฟล์ (File Descriptions)

### 1. `dashboard_page.dart`
- **หน้าที่หลัก**: เป็นตัวรับค่าและเป็นหน้าต่างทางเข้าหลัก (Entrypoint)
- **การทำงาน**:
  - โหลดและตรวจจับ State จาก `AppStateProvider` (เช่น เช็คสถานะ Loading, เช็ค Error)
  - จัดการแสดงหน้าโหลดหมุนๆ (`_LoadingView`) หรือแสดงหน้าจอผิดพลาดกรณีมี Error (`_ErrorView`)
  - หากโหลดข้อมูลสำเร็จ จะส่งข้อมูล Trip และข้อมูลลูกค้าไปแสดงผลที่ `DashboardMapContent`

### 2. `widgets/dashboard_map_content.dart`
- **หน้าที่หลัก**: ไฟล์ที่ใหญ่ที่สุดและคุมการทำงานของแผนที่และข้อมูลสถิติด้านบนทั้งหมด
- **การทำงาน**:
  - วาดแผนที่แบบเต็มหน้าจอ (`FlutterMap`)
  - คุมการซูมและตำแหน่งแผนที่ (`MapController`)
  - ทำการคำนวณแบ่งกลุ่มลูกค้าด้วยระยะทางอัตโนมัติอ้างอิงตามระดับการซูม (Grid-based Proximity Clustering) เพื่อความลื่นไหลและดูง่าย
  - วาดพิกัดจุดนำทางและแสดงจุดของผู้ใช้ปัจจุบัน (`_buildUserLocationDot`)
  - จัดการเหตุการณ์เมื่อพิมพ์ค้นหาในแถบค้นหา และเปิดลิสต์รายการผลลัพธ์การค้นหา
  - ควบคุมการกดปุ่มขอระบุพิกัดตำแหน่งปัจจุบัน (`_centerOnUser`)

### 3. `widgets/glass_search_bar.dart`
- **หน้าที่หลัก**: แถบค้นหากึ่งโปร่งใส (Glassmorphism design)
- **การทำงาน**: รับอินพุตข้อความพิมพ์ค้นหาชื่อลูกค้า ที่อยู่ หรือเบอร์โทรศัพท์ และส่งค่าคืนกลับไปตัวแม่เมื่อมีการเปลี่ยนแปลง

### 4. `widgets/action_button.dart`
- **หน้าที่หลัก**: ปุ่มกดยาวดีไซน์ไล่สีสวยงาม (Gradient Pill-shaped Button)
- **การทำงาน**: มีโครงสร้าง `ScaleTransition` เพื่อทำเอฟเฟกต์ย่อตัวลงเล็กน้อยตอนโดนนิ้วกด และเด้งคืนรูปเดิมเมื่อปล่อยนิ้ว เพิ่มความน่ากดใช้งาน (Micro-interaction)

### 5. `widgets/customer_bottom_sheet.dart`
- **หน้าที่หลัก**: เมนูแสดงรายละเอียดลูกค้าเดี่ยวเมื่อผู้ใช้จิ้ม Marker สีส้ม/เขียว บนแผนที่
- **การทำงาน**:
  - แสดงภาพอักษรย่อ, ชื่อ, เบอร์โทร และที่อยู่ลูกค้า
  - มีปุ่มทางลัด: **โทรหา** (เปิดแอปพลิเคชันโทรศัพท์), **นำทาง** (เปิด Google Maps นำทางภายนอก), และ **วางแผนเส้นทางส่งของ** (เปลี่ยนหน้าไปหน้าคำนวณเส้นทาง Route Planning)

### 6. `widgets/cluster_bottom_sheet.dart`
- **หน้าที่หลัก**: เมนูลิสต์แสดงรายการลูกค้ากลุ่มใหญ่ในบริเวณเดียวกันเมื่อผู้ใช้คลิกเลือกกลุ่มตัวเลขบนแผนที่
- **การทำงาน**: แสดงผลลูกค้าทั้งหมดในกลุ่มนั้นในรูปแบบรายการ (ListView) และมีปุ่มสำหรับ **ระบุพิกัด** (เพื่อซูมไปจุดเฉพาะของคนนั้น), **โทรหา** หรือ **นำทาง**

### 7. `widgets/fade_in_slide.dart`
- **หน้าที่หลัก**: วิดเจ็ตอนิเมชันสำหรับเอฟเฟกต์การแสดงผล
- **การทำงาน**: ค่อยๆ ทำการเปลี่ยนค่าความโปร่งใส (Fade in) และเลื่อนขึ้นจากขอบล่างช้าๆ (Slide transition) เพื่อให้ UI ดูไหลลื่นและพรีเมียม
