# โฟลเดอร์ระบบวางแผนเส้นทาง (Route Planning)

โฟลเดอร์นี้ได้รับการแยกไฟล์ (Refactored) ออกเป็นคอมโพเนนต์ย่อยเรียบร้อยแล้ว เพื่อแบ่งหน้าที่การทำงานให้โค้ดมีความคลีน อ่านง่าย และบำรุงรักษาได้สะดวกในระยะยาว

---

## 📂 โครงสร้างโฟลเดอร์ (Folder Structure)

```text
lib/screens/route_planning/
├── README.txt                         # ไฟล์อธิบายโครงสร้างระบบหลัก (ไฟล์นี้)
├── route_planning_page.dart           # จุดเข้าหลัก (Entrypoint Wrapper) คุม Context และ Provider
└── widgets/
    ├── route_planning_content.dart    # ตัวควบคุมหลัก (State Controller) จัดการแผนที่, พิกัด GPS และการเรียงคิว
    ├── route_planning_setup_view.dart # หน้าจอตั้งค่า (Setup Mode) ค้นหา ติ๊กเลือก จัดเรียง และเริ่มนำทาง
    ├── route_planning_navigation_view.dart # หน้าจอนำทางขณะขับรถส่งของจริง (Active Navigation Mode)
    └── route_planning_widgets.dart    # ไฟล์รวมวิดเจ็ตย่อย เช่น ปุ่มไล่โทนสี, การ์ดแสดงคิว, เม็ดยาสรุปตัวเลข
```

## 📄 เจาะลึกหน้าที่ของแต่ละไฟล์ (Detailed File Descriptions)

### 1. `route_planning_page.dart`
- **หน้าที่หลัก**: จุดเข้าใช้งานระบบหลัก (Stateless Entrypoint Shell)
- **การทำงาน**: ทำหน้าที่เช็คโหลด `AppStateProvider` และสร้าง Context ครอบตรรกะทั้งหมด เพื่อป้อนส่งต่อให้ตัวเนื้อหาหลัก (`RoutePlanningPageContent`)

### 2. `widgets/route_planning_content.dart`
- **หน้าที่หลัก**: ตัวควบคุมกลาง (Core State Controller)
- **การทำงาน**:
  - เป็นจุดเก็บ State และตรรกะระบบนำทางทั้งหมด (เช่น รายการคิวคงเหลือ, คิวที่ส่งเสร็จ, ละติจูด/ลองจิจูดล่าสุด)
  - ทำหน้าที่สลับหน้าจอ (Switch Views) ระหว่าง Setup (ตั้งค่า) และ Navigation (นำทางจริง)
  - คุมการค้นหา และประมวลผลอัลกอริทึมหาเส้นทางที่เร็วและสั้นที่สุด (Nearest Neighbor) ผ่าน OSRM/OSM
  - มีระบบตรวจจับสัญญาณ GPS จากมือถือคนขับแบบ Real-time และขยับแผนที่ตามรถ

### 3. `widgets/route_planning_setup_view.dart`
- **หน้าที่หลัก**: หน้าตั้งค่าก่อนเดินทาง (Setup Screen View)
- **การทำงาน**:
  - แสดงภาพแผนที่จำลองตำแหน่งของลูกค้าแต่ละท่าน
  - มีช่องเสิร์ชรายชื่อลูกค้าและเบอร์โทร
  - มีระบบติ๊กเลือกรายชื่อคนที่จะจัดส่งด้วยปุ่ม **"เลือกทั้งหมด / ล้างทั้งหมด"** เพื่อความสะดวก
  - แสดงข้อมูลสรุปยอดพิกัด ระยะทาง และเวลาที่จะใช้เดินทางก่อนเริ่มกดนำทาง

### 4. `widgets/route_planning_navigation_view.dart`
- **หน้าที่หลัก**: หน้านำทางขับรถจริง (Active Navigation Screen View)
- **การทำงาน**:
  - ทำหน้าที่เสมือนเป็น GPS นำทาง แสดงหมุดสีส้มของลูกค้าคิวถัดไป พร้อมเขียนทิศทางที่ต้องขับรถไป
  - มีปุ่มสั่งล้างคิวหรือปุ่ม Fit แผนที่ให้เข้าพิกัด
  - มีปุ่มทางลัดโทรหาลูกค้าคิวปัจจุบัน, ปุ่มเปิดนำทางต่อในแอป Google Maps นอก
  - มีปุ่มแตะส่งสำเร็จเพื่อสลับไปยังเป้าหมายคนต่อไปอัตโนมัติ

### 5. `widgets/route_planning_widgets.dart`
- **หน้าที่หลัก**: โกดังเก็บปุ่มและหน้าต่างย่อย (Shared Custom UI Components)
- **การทำงาน**:
  - `QueueItemCard`: การ์ดสี่เหลี่ยมระบุชื่อลูกค้าและระยะทางในหน้าจัดคิว
  - `AnimatedGradientButton`: ปุ่มสีเขียวไล่เฉดสีที่มีลูกเล่นกระพริบอนิเมชันน่าดึงดูดสายตาตอนพร้อมนำทาง
  - `SummaryPillItem`: แท็บเม็ดแคปซูลเล็กๆ ที่อยู่ขวาบนของแผนที่แสดงจำนวนจุดเดินทาง ระยะทาง กม. และนาที
